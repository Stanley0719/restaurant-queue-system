# 餐廳排隊點餐系統

這是一個簡單的靜態前端專案，會顯示：

- 第一號
- 最後一號
- 目前叫號
- 待叫號列表

## 啟動方式

直接用瀏覽器開啟 `index.html` 即可，或使用本地伺服器：

```bash
python -m http.server 8000
```

接著前往：

```text
http://localhost:8000/
```

## GitHub Pages 部署

1. 在 GitHub 建立一個新 repository。
2. 把這個資料夾推到 GitHub。
3. 到 repository 設定頁面，找到 `Pages`。
4. 選擇 `Deploy from a branch`，branch 選 `main`，folder 選 `/root`。
5. 儲存後即可取得 GitHub Pages 網址。
